The Story of Art

About this CD

This CD contains the following folders:

  • install
    This folder contains the installation files for the final version of the piece along with detailed installation instructions.
  • adobe SVG viewer
    This folder contains installers for Adobe's SVG viewer software, which is required to play the piece. For more software requirements, please see the detailed installation instructions.
  • examplesThis folder contains 5 examples from the piece which can be run separately from the main piece. These examples will play once and then stop (rather than loop continuously), and are self-contained (i.e. they do not require any additional files in order to run).
  • docsThis folder contains a report of the timings of the piece, and the abstract submitted to the svgOpen conference 2005 by e-2.
  • tate versionThis folder contains the version which was used for the show at the Tate. This version is incomplete and should not be used - it is included here for reference purposes only.
  • filesThis folder contains the individual files which are needed to run the piece.

Running The Story of Art on non-Windows platforms

In order to run The Story of Art on Linux or Macintosh, you will need to first install the SVG viewer application (installers for different platforms are included in the adobe SVG viewer directory). Then, the files will need to be copied from the files directory on this CD to a suitable directory on your system, and the piece started by opening the file soa0.svg from within this folder.

Please note that the piece has not been tested on any other platforms, and is not guaranteed to run.
