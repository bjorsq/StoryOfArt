The Story of Art

The Story of Art is comprised of a series of SVG files and an external script file. Each of the SVG files contains animated text, and when the animation has finished playing, the next file in the sequence is loaded automatically. In this way, the piece runs sequentially through all the files, and loops back on itself when it reaches the end.

Installation Instructions

These instructions can be downloaded here as a Word 6.0/95 document or a PDF document.

System Requirements

  • 3.0GHz processor or faster. Multiple processors may also help increase the quality of the animation (the SVG files require a great deal of processor power).
  • 256 Mb RAM
  • 20 Mb hard disk space
  • Windows 2000/XP or later
  • Internet Explorer version 6 or above.
  • Adobe SVG Viewer version 3 or above
    This is available as a free download from the Adobe website: see this page for details. Installers for various platforms are also available on this CD in the adobe SVG viewer folder.

Installation

  1. Unzip the files to C:\soa by double-clicking on the StoryOfArt.exe file on this CD in the install folder (here).
  2. You should have 102 files in this directory, called soa[0-101].svg, and one file called soa_parts.es.
  3. Verify that you can play one of the SVG files by double clicking on it. If Adobe SVG Viewer is installed correctly, this should open Internet Explorer, load the SVG viewer plug-in, and start to play the animation.
  4. Make a shortcut to the first file in the piece by right-clicking on the desktop and choosing New->Shortcut from the menu.
  5. Type the following where it says "type the location of the item":
    "C:\Program Files\Internet Explorer\IEXPLORE.EXE" -k "C:\soa\soa0.svg"
    The above will produce a link to the SVG file on the desktop which will open in Internet Explorer in "kiosk mode". Kiosk mode disables all mouse-driven menus in Internet Explorer, but does not disable the mouse or hide it (this has to be done manually).
  6. Make sure the computer on which it installed does not go to sleep, or switch off the monitor, by checking the Power Options (Start->Control Panel->Power Options).

Running the piece

Starting the piece manually

  1. Double click on this shortcut you created in steps 4. and 5. above to start the piece.
  2. Move the mouse off-screen.
  3. Once started, the piece should loop indefinitely without reloading.

Starting the piece automatically

  1. Copy the shortcut you created in steps 4. and 5. above to the startup folder (in Start->Programs), so the piece starts automatically when the machine boots.
  2. Restart the machine to test.

Shutting down the piece

Press Alt+F4 on the keyboard to shut the piece down.

Troubleshooting

If the piece stops for any reason, or begins to look strange, jerky or in any way abnormal, restart the piece by pressing Alt-F4 on the keyboard and double-clicking the shortcut again. If this doesn't fix the problem, restart the machine (and then restart the piece again if you haven't set the piece to start automatically).

The animation requires a lot of resources in which to run - mainly processor power. If there are any programs running on the machine which take up processor time (such as anti-virus programs), they may cause the piece to run less smoothly. The installation at the Tate Modern used a brand new PC with a fresh install of Windows XP Professional - all unnecessary services were disabled, and the only software installed (other than the operating system) was the SVG viewer.

Alternative platforms

As the animation requires the minimum of a fast processor and the presence of Adobe's SVG viewer, it can probably run on linux, solaris and macintosh computers as well (installers for these platforms are included on this CD in the adobe SVG viewer folder). However, none of these platforms have been tested yet.

If you wish to install The Story of Art on one of these alternative platforms, you will need to copy all the files from the files folder to your hard drive, and start the piece by opening soa0.svg.
